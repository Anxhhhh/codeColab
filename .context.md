# Project Context: codeColab

## Overview
codeColab is a real-time collaborative code editor designed to provide a seamless multi-user editing experience similar to VS Code's Live Share.

## Tech Stack
- **Frontend**:
  - Framework: React (Vite)
  - Editor: Monaco Editor (`@monaco-editor/react`)
  - Styling: TailwindCSS
  - Icons: Lucide React
  - Sync/CRDT: Yjs, y-monaco, y-socket.io
- **Backend**:
  - Runtime: Node.js
  - Framework: Express
  - Communication: Socket.io
  - Sync Server: y-socket.io

## Key Components & Architecture

### Frontend (`/client`)
- `src/app/App.jsx`: Main entry point. Handles:
  - User authentication (simple username prompt).
  - Yjs document and SocketIOProvider initialization.
  - Monaco Editor binding with Yjs for real-time sync.
  - UI layout (Activity Bar, Sidebar for participants, Editor, Status Bar).
- `test-sync.js`: Likely a script for testing synchronization logic outside the main UI.

### Backend (`/server`)
- `server.js`: Express server that:
  - Serves static files from the `public` directory.
  - Initializes Socket.io and YSocketIO server for document synchronization.
  - Includes a `/health` endpoint.

### Infrastructure
- `dockerfile`: Multi-stage build process.
  - Stage 1: Builds the React app.
  - Stage 2: Sets up the Node server and serves the built frontend assets.
- `README.md`: Contains project overview, technology list, and AWS deployment guides (ECS, Elastic Beanstalk, App Runner).

## Recent Operations & State
- Project is containerized and ready for cloud deployment.
- Basic collaboration (text sync and participant list) is implemented.
- UI is styled to mimic VS Code's aesthetic.
